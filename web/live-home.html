JIANT LIVE v0.2

Performance-oriented FM1 firmware with six independently assigned MIDI receive channels, 32 MIDI Learn destinations with shared CCs, and 12 editable DRUM-X sounds. The original synthesizer engines, effects and sequencer remain available.

Try the emulator

Audition sounds, test MIDI routing and import a backup in the browser.

FM1 installer

Install the Jiant Live package via USB-MIDI using a supported browser.

Web editor

Edit sounds and projects, and back up or restore FM1 data.

Interactive manual

Inherited JIANT reference; Jiant Live MIDI controls differ.

Experimental: Jiant Live has been successfully flashed to a physical FM1, but broader hardware validation and recovery testing remain incomplete. Make an external backup and prepare a recovery method before installing. This installer publishes only Jiant Live firmware.

Live MIDI control

Assign any MIDI channel (1–16) to each of six tracks, layer tracks on the same channel, and assign one incoming CC to several parameters at once.
